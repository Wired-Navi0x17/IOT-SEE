How the score travels

01 · DATA

CricketData API

Live scores, polled every 2½ min to stay inside 100 free calls a day.

02 · BRAIN

UNO Q hub

Python hub in Docker on the board's Linux side. Stores matches, runs the simulator.

03 · LINK

UART wire

UNO Q MCU relays JSON to the screen at 115200 baud over 3 wires.

04 · SCREEN

CYD display

ESP32 2.8″ touch screen. Tap to switch screens, hold for the QR code.

Run it from a phone

The UNO Q hosts its own WiFi, UCIS-Cricket. Open the dashboard to pick the screen, set up a simulation with two teams, their batting order and bowlers, then pause, resume or speed it up. Brightness, rotation and the QR code are controlled from there too.
