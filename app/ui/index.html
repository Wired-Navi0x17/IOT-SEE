Connect to the hub

The dashboard runs on the Arduino UNO Q. Join its WiFi, then connect.

On the UNO Q hotspot this is 10.42.0.1:8000. On another network, use the IP the dashboard shows under Device.

  • 1. Power the UNO Q and wait about a minute for it to boot.
  • 2. Join the WiFi network SEEv2-Cricket.
  • 3. Tap Connect. Use the phone's back button to return here.
